# 历史资料索引

本目录用于隔离不再代表当前实现、当前契约或当前验收状态的历史资料。归档内容不能作为功能已完成、性能已达标、格式兼容或迁移受支持的证据；当前行为以仓库根目录 `README.md`、`docs/`、公开头文件和自动化测试为准。

## 本地规划归档

`archive/planning/` 在 `.gitignore` 中，仅保留于整理过的开发工作区，不随仓库发布。原文保持不变，状态如下：

| 文件 | 状态 | 原因 |
|---|---|---|
| `plan.md` | 已取代、部分完成 | 记录早期可靠性演进，其中写路径、WAL 和 compaction 架构描述已不对应当前单文件实现。 |
| `production-plan.md` | 已取代、未作为验收执行 | “Current Gaps” 是历史快照，部分条目已经实现，部分资格证据仍缺失。 |
| `post-production-plan.md` | 已废弃、部分实验已回退 | 包含后来移入 `legacy_v1_v2` 的模块拆分方案，不能当作当前模块图。 |
| `next-phase-plan.md` | 已取代、未完整达标 | 多处 “已完成” 只表示当时实现状态，不等于当前回归或 qualification 证据。 |
